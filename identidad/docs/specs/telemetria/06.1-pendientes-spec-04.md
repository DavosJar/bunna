# 06.1 — Pendientes del decorador

> **Propósito**: Listar lo que falta implementar/corregir en los decoradores de telemetría.

---

## Pendientes

### 1. Usar `LogPayload` en vez de map plano

Los 4 decorators construyen un `map[string]any` plano. Deben usar `telemetry.LogPayload` con `NegocioFields` para que el JSON salga anidado con `"negocio": { ... }`.

---

### 3. `ToLog()` en comandos

Cada comando necesita el método `ToLog() map[string]any` que excluya campos sensibles. Aplica a todos los `Comando*` de dominio.

---

### 4. Decoradores para los casos de uso sin interfaz

Una vez creadas las interfaces, crear `decorator_*.go` para cada una. Al menos 32 decoradores nuevos.

---

### 5. Type assertion frágil en logout

```go
return resp.(*uc_logout.RespuestaCerrarSesion), nil
```

Puede panic. Cambiar a type assertion con chequeo.

---

### 6. Duration como `float64`

`time.Since(start).Milliseconds()` es `int64`. `DurationUsecaseMs` en `NegocioFields` es `float64`. Convertir al asignar.
